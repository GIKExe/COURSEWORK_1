# Система анализа и аугментации данных для изображений

Данное приложение представляет собой комплексную систему для автоматизированного анализа, сегментации и создания аугментированных датасетов на основе исходных изображений. Оно предназначено для исследовательских задач в области компьютерного зрения и медицинского/технического анализа.

## Основные модули
Приложение реализовано с использованием графического интерфейса (GUI) и имеет три основных рабочих режима:

### 1. Сегментация (Segmentation)
Модуль позволяет пользователю вручную или полуавтоматически выделить области интереса (ROI) на изображении. Это ключевой этап, который определяет границы объекта для дальнейшего анализа.

*   **Функционал:** Пошаговое определение контуров и границ объектов.
*   **Основной файл:** `src/gui/segmentation_app.py`

### 2. Инспекция и Измерение (Inspection and Measurement)
После сегментации модуль позволяет провести детальный анализ выделенной области, измеряя различные параметры.

*   **Функционал:** Автоматическое или ручное измерение геометрических параметров (площадь, периметр, отношение сторон и т.д.), расчет метрик объекта. Данные измерений сохраняются в структурированном виде.
*   **Основной файл:** `src/gui/inspection_app.py`, `src/core/measurement.py`

### 3. Аугментация данных (Augmented Inspection)
Самый продвинутый модуль, предназначенный для автоматического создания расширенного и аугментированного набора данных из исходного изображения и результатов анализа. Это критически важно для обучения моделей машинного обучения при нехватке реальных размеченных данных.

*   **Функционал:** Генерируется серия модифицированных изображений, сопровождаемых соответствующими файлами метаданных (JSON-контуров) для каждого аугментации.
*   **Основной файл:** `src/gui/aug_inspection_app.py`
*   **Выходные данные:** Результаты сохраняются в директорию `out`, включая оригинальные изображения, файлы контуров и обработанные метаданные.

## Режимы работы
1.  **GUI (Пользовательский интерфейс):** Предоставляет пошаговый рабочий процесс, позволяющий переключаться между режимами Сегментация -> Инспекция -> Аугментация в рамках одного сеанса.
2.  **Batch Mode (Режим пакетной обработки):** Позволяет запускать анализ на серии изображений командной строкой для автоматической обработки большого объема данных без участия пользователя.

## Структура проекта
*   `src/core/`: Содержит основную, ядровую логику приложения (расчеты, обработка контуров, I/O, математические модели).
*   `src/gui/`: Реализует графический пользовательский интерфейс для взаимодействия с пользователем.
*   `src/main.py`: Точка входа в приложение, управляющая переключением между различными модулями GUI или запуском пакетного режима.
